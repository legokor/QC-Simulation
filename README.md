# QC-Simulation
Simulator of quadcopter based on non-linear physics model and CAD files in Matlab/Simulink/Simscape environment

repository is configured to use LFS
- to install it: git lfs install
- to apply it on nondefault file: git lfs track "file"
- including videos, images, compressed, CAD, matlab logs and data (todo: simulink logs)


Github from linux
- sudo apt install gh (install github CLI [ubuntu, debian])
- gh auth login (follow convenient steps)
